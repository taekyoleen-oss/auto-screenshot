# Auto Screenshot — 자동 페이지 캡처

화면을 **페이지 단위로 넘기면서 전체 화면 스크린샷을 자동으로 찍어** 새 폴더에 번호 순서대로 저장하는 Windows 앱입니다.
원격 데스크톱·터미널에서 작업한 긴 결과를 이미지로 쉽게 받아 오는 용도로 만들었습니다.

- 소개·다운로드 페이지: https://auto-screenshot-six.vercel.app
- 실행 파일: [Releases](../../releases/latest) 에서 `AutoScreenshot.exe` 다운로드

## 기본 동작 — 설정 없이 [캡처 시작]만
캡처할 화면(원격 데스크톱, 터미널, 문서 등)을 **화면 가운데**에 띄워 두고 **▶ 캡처 시작**을 누르면, 매 페이지마다 다음을 반복합니다.

1. 마우스가 **화면 가운데를 클릭** → 그 자리의 앱 활성화
2. **Page Down** 전송
3. 마우스가 **이 앱의 캡처 패널로 돌아와 클릭** → 이 앱 활성화
4. 이 앱이 활성화된 상태에서 **전체 화면 캡처** (패널은 캡처 순간에만 투명 처리)

대상 앱이 비활성 상태에서 찍히므로 **글자 커서와 마우스 포인터가 이미지에 남지 않고**, 대상 앱이 활성 상태일 때만 걸리는 캡처 제한도 피할 수 있습니다.

- 화면이 더 이상 바뀌지 않으면(끝 도달) 자동으로 멈춥니다.
- **Esc** 또는 **마우스를 직접 움직이면** 즉시 중지합니다. (원격 화면에서는 Esc가 원격으로 넘어갈 수 있어 마우스 움직임으로도 멈출 수 있게 했습니다)
- 저장 위치: `저장 폴더\Screenshot_<날짜>_<시간>\0001.png, 0002.png …`

## 필요할 때만 — ⚙ 설정 변경
| 설정 | 기본값 | 바꿀 수 있는 값 |
|---|---|---|
| 캡처 대상 | 화면 가운데 앱 (원격·터미널 포함) | 목록에서 특정 창 선택 |
| 클릭 위치 | 화면 가운데 | 📍 지정 → 화면의 원하는 곳을 한 번 클릭 |
| 캡처 영역 | 전체 화면 | 대상 창 영역만 / 모든 모니터 |
| 페이지 이동 | Page Down | Shift+Page Down(터미널) / Space / ↓ / 마우스 휠 |
| 시작 위치 | 현재 위치 | Ctrl+Home / Ctrl+Shift+Home |
| 동작 방식 | 마우스 클릭 전환 | 키 입력만 (빠름) |
| 기타 | 최대 50장, 페이지 간 0.8초, 시작 전 3초, PNG | 장수·대기 시간·JPG·PDF 합치기·끝 감지 끄기 |

설정을 바꾸면 기본 화면 상단의 "현재 설정" 요약에 바로 반영되고, 다음 실행 때도 유지됩니다. **모든 설정 기본값으로** 버튼으로 언제든 되돌릴 수 있습니다.

## 대상별 팁
| 대상 | 권장 |
|---|---|
| 원격 데스크톱(전체 화면) | 기본값 그대로 |
| 원격/로컬 터미널 출력 기록 | 페이지 이동 `Shift+Page Down`, 시작 위치 `Ctrl+Shift+Home` |
| 문서·PDF·브라우저 | 기본값, 맨 위부터 찍으려면 시작 위치 `Ctrl+Home` |
| 화면 가운데에 링크·버튼이 있는 경우 | 클릭 위치를 빈 곳으로 지정 |

## 실행
- `AutoScreenshot.exe` 실행, 또는 소스에서 `run.bat` (= `pythonw auto_screenshot.py`)
- 소스 실행 시 필요: Python 3.9+, `pip install -r requirements.txt` (Pillow)
- exe 직접 빌드: `build_exe.bat` → `dist\AutoScreenshot.exe`

## 참고
- 클릭 위치에 앱이 없으면(바탕화면) 시작하지 않고 알려 줍니다. 진행 중 다른 창이 끼어들면 엉뚱한 곳에 입력이 가지 않도록 바로 멈춥니다.
- 운영체제 수준의 캡처 차단(Display Affinity, DRM 영상 등)은 포커스와 관계없이 검게 찍히며, 이를 우회하지 않습니다.
- 관리자 권한으로 실행된 창은 이 앱도 관리자 권한으로 실행해야 클릭·키 입력이 전달됩니다.
- 설정은 `%USERPROFILE%\.auto_screenshot.json`에 저장됩니다.

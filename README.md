# Auto Screenshot — 자동 페이지 캡처

선택한 창(터미널, 메모장, PDF 뷰어, 브라우저 등)을 **페이지 단위로 넘기면서 자동으로 스크린샷을 찍어** 새 폴더에 번호 순서대로 저장하는 Windows 앱입니다.

- 소개·다운로드 페이지: https://auto-screenshot.vercel.app
- 실행 파일: [Releases](../../releases/latest) 에서 `AutoScreenshot.exe` 다운로드

## 동작 방식 — 마우스 클릭 전환 (기본)
매 페이지마다 다음을 반복합니다.

1. 마우스가 **대상 창의 클릭 위치로 이동해 클릭** → 대상 창 활성화
2. **Page Down** 등 페이지 이동 키 전송
3. 마우스가 **이 앱의 캡처 패널로 돌아와 클릭** → 이 앱 활성화
4. 이 앱이 활성화된 상태에서 **캡처** (패널은 캡처 순간에만 투명 처리)

대상 창이 비활성 상태에서 찍히므로 **글자 커서(캐럿)와 마우스 포인터가 이미지에 남지 않고**, 대상 앱이 활성 상태일 때만 캡처를 막는 경우에도 캡처할 수 있습니다.
빠르게 찍고 싶으면 동작 방식을 `키 입력만 (빠름)`으로 바꾸세요.

## 실행
- `AutoScreenshot.exe` 실행, 또는 소스에서 `run.bat` (= `pythonw auto_screenshot.py`)
- 소스 실행 시 필요: Python 3.9+, `pip install -r requirements.txt` (Pillow)
- exe 직접 빌드: `build_exe.bat` → `dist\AutoScreenshot.exe`

## 사용 방법
1. 캡처할 파일이나 터미널을 먼저 열어 둡니다.
2. **① 캡처할 창 선택** 목록에서 그 창을 고릅니다. (선택한 창만 캡처합니다)
3. 필요하면 **클릭 위치 → 📍 지정**을 누르고 대상 창의 빈 곳(링크·버튼이 없는 곳)을 한 번 클릭합니다. 지정하지 않으면 창 중앙을 클릭합니다.
4. **▶ 캡처 시작** → 카운트다운 후 자동 진행. 진행 중에는 **마우스를 건드리지 마세요.**
5. 화면이 더 이상 바뀌지 않으면(문서 끝) 자동으로 멈춥니다. **Esc** 또는 패널의 **■ 중지**로 언제든 중지합니다.
6. 저장 위치: `상위 폴더\<폴더이름>_<날짜>_<시간>\0001.png, 0002.png …` (PDF 합치기 옵션 사용 시 PDF도 생성)

## 대상별 권장 설정
| 대상 | 시작 위치 | 페이지 이동 방식 |
|---|---|---|
| 메모장·Word·VS Code 등 문서 | Ctrl+Home | Page Down |
| Windows Terminal / PowerShell 출력 기록 | Ctrl+Shift+Home | Shift+Page Down |
| 웹 브라우저·PDF 뷰어 | 현재 위치 또는 Ctrl+Home | Page Down 또는 Space |
| 키가 안 먹는 앱 | 현재 위치 | 마우스 휠 (반복 횟수로 이동량 조절) |

## 참고
- 캡처 중 예상과 다른 창이 활성화되면, 엉뚱한 창에 클릭·키 입력이 가지 않도록 바로 중지합니다.
- 앱이 운영체제 수준의 캡처 차단(Display Affinity, DRM 영상 등)을 쓰면 포커스와 관계없이 검게 찍힙니다. 이 경우는 우회하지 않습니다.
- 관리자 권한으로 실행된 창은 이 앱도 관리자 권한으로 실행해야 클릭·키 입력이 전달됩니다.
- 설정은 `%USERPROFILE%\.auto_screenshot.json`에 자동 저장됩니다.
